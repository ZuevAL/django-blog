# Django Blog Platform

Современное веб-приложение для публикации статей, разработанное на Django. Проект демонстрирует навыки построения сложных связей в БД, работы с кастомными менеджерами и обеспечения безопасности контента.

## Основной функционал и технические решения

### 🔹 Backend & ORM
- **Кастомные QuerySets:** Реализован `PublishedManager` для фильтрации опубликованных постов на уровне БД.
- **Система рекомендаций:** Реализован алгоритм подбора похожих статей на основе пересечения тегов с использованием агрегации (`annotate`, `Count`).
- **Связи в БД:** Использование `ForeignKey` для организации структуры «Пост — Комментарии» и «Автор — Посты».

### 🔹 Расширенный функционал
- **Тегирование:** Интеграция `django-taggit` для классификации контента.
- **Интеграция Email:** Реализована отправка рекомендаций постов через SMTP.
- **Пагинация:** Постраничный вывод списков статей (по 3 поста на страницу).

### 🔹 Безопасность и шаблонизация
- **Защита от XSS:** Использование библиотеки `nh3` для санитизации (очистки) HTML-кода при рендеринге Markdown.
- **Custom Tags:** Разработаны `inclusion_tag` и `simple_tag` для вывода статистики и последних постов в сайдбаре.

## Стек технологий
- **Core:** Python 3.13+, Django 5.x.
- **Tools:** Django ORM, SQLite, Tag-git, nh3, Markdown.

## Как запустить проект локально
1. Клонировать репозиторий.
2. Создать виртуальное окружение: `python -m venv venv`.
3. Установить зависимости: `pip install -r requirements.txt`.
4. Выполнить миграции: `python manage.py migrate`.
5. Создать суперпользователя: `python manage.py createsuperuser`.
6. Запустить сервер: `python manage.py runserver`.
